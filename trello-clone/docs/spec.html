Learning Project — Requirements

タスクボード要件定義書

最終更新: 2026-09-10 版数: v1.0 ステータス: 最小機能セット完成

01背景・目的

プログラミング未経験者が、学習課題としてTrello風のタスク管理アプリを制作する。 目的は成果物そのものより、DOM操作・イベント処理・状態の永続化(localStorage)といった Webフロントエンドの基礎を、手を動かしながら習得することにある。

02スコープ

個人のブラウザ内で完結する、単一ユーザー向けのタスクボード。列は「未着手」「進行中」「完了」の 3つに固定し、カード単位でタスクを管理する。

未着手
進行中
完了

03対象ユーザー

開発者自身。他者とのアカウント共有やチーム利用は想定しない、個人のタスク管理用途。

04機能要件

実装済みの機能を操作カテゴリごとに整理したもの。

カードの基本操作
FR-01追加
各列の入力欄に入力し、「追加」ボタンまたはEnterキーでカードを作成する。
FR-02削除
カード右上の「×」ボタンでそのカードを削除する。
FR-03編集
カードのテキストをダブルクリックすると入力欄に切り替わる。Enterで確定、Escapeで取り消し。
カードの移動
FR-04ボタン移動
カード右上の「→」ボタンで、隣(右)の列へ1つ移動する。
FR-05ドラッグ&ドロップ
カードを掴んで任意の列にドロップすると、その列の末尾へ移動する。
ラベル(色分け)
FR-06色を選ぶ
カード左側の丸ボタンから、5色+「ラベルなし」の中から1つを選択する。
FR-07表示
選んだ色がカード左端の縦バーとボタン自体の塗りに反映される。
データの保存
FR-08自動保存
追加・削除・編集・移動・ラベル変更のたびに、ボード全体の状態を保存する。
FR-09復元
ページを再読み込みすると、保存済みの状態から3列すべてを再構築する。

05非機能要件

NFR-01動作環境
最新のデスクトップ向けモダンブラウザ(Chrome / Edge / Firefox / Safari)。サーバーは不要で、HTMLファイルを開くだけで動作する。
NFR-02実装技術
素のHTML / CSS / JavaScriptのみ。フレームワーク・ビルドツール・外部ライブラリへの依存を持たない。
NFR-03永続化方式
ブラウザのlocalStorageにJSON形式で保存する。バックエンド・データベースは持たない。

06データ要件

localStorageのキー"trello-clone-board"には、列ごとのカード配列を そのままJSON文字列化したものが入っている。列の順序が配列のインデックス(0〜2)に対応する。 

// localStorage["trello-clone-board"]
[
  // 0: 未着手
  [
    { "text": "要件をまとめる", "color": "#0079bf" }
  ],
  // 1: 進行中
  [
    { "text": "カード編集機能", "color": "#eb5a46" },
    { "text": "ラベルUI改善", "color": "#61bd4f" }
  ],
  // 2: 完了
  [
    { "text": "3列レイアウト", "color": "#f2d600" }
  ]
]

07制約条件・対象外

今回のスコープには含めない、または前提として割り切っている事項。

  • 複数デバイス間の同期データは端末・ブラウザごとのlocalStorageに閉じており、他のデバイスや他のブラウザとは共有されない。
  • ユーザー認証ログイン機能は持たない。ブラウザを開いた人が唯一の利用者という前提。
  • 列の追加・削除列は「未着手」「進行中」「完了」の3つに固定し、増減させる機能は持たない。
  • 期限日・検索・絞り込み今回のスコープには含めない。将来の拡張候補とする。
