# 機能一覧

## フェーズ1（基本機能）

| 機能 | 概要 |
| --- | --- |
| 列表示 | 「未着手」「進行中」「完了」の3列を表示する |
| カード追加 | 任意の列にカード（タイトル・期限・優先度）を新規作成する |
| カード削除 | カードを削除する |
| カード編集 | カードのタイトル・期限・優先度を変更する |
| カード移動・並び替え | カードをドラッグ&ドロップで別の列、または同一列内の任意の位置へ移動する（自由な順序） |
| 優先度順ボタン | 列ごとに、押した時点でカードを優先度順に並び替える |
| 期限順ボタン | 列ごとに、押した時点でカードを期限順に並び替える（期限未設定は末尾） |

- 受け入れ基準・ユースケースは [機能要件](./functional-requirements.md) を参照
- 画面上の見た目・操作方法は [画面設計](./screen-design.md) を参照
