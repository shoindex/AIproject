# 機能一覧

## フェーズ1（基本機能）

| 機能 | 概要 |
| --- | --- |
| 列表示 | 「未着手」「進行中」「完了」の3列を表示する |
| カード追加 | 任意の列にカードを新規作成する |
| カード削除 | カードを削除する |
| カード編集 | カードのタイトルを変更する |
| カード移動 | カードを別の列へ移動する |

- 受け入れ基準・ユースケースは [機能要件](./functional-requirements.md) を参照
- 画面上の見た目・操作方法は [画面設計](./screen-design.md) を参照
